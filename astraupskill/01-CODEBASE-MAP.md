# 1. Map the request path

Begin at [`QuoteBuilder.tsx`](../src/PeblClone.Web/src/features/QuoteBuilder.tsx). Its props contain `countries`; local state holds `countryIsoCode`, `employmentType`, `monthlyCompensation`, `quote`, `isLoading`, and `error`. The form submit handler prevents a browser navigation, clears the old result and error, marks the request loading, and asks `createQuote` to send the four fields. The form uses a hardcoded `currency: 'USD'`, so its displayed label is fixed by this screen.

Continue to [`workforceApi.ts`](../src/PeblClone.Web/src/services/workforceApi.ts). `createQuote` delegates to the generic `request<T>` helper with `POST`, JSON serialization, and `/api/workforce/quotes`. The helper reads an unsuccessful response body as text, attempts to extract ProblemDetails `detail` or `title`, and throws an `Error`. That throw crosses the API function boundary unchanged. `getDashboard` is intentionally different: it catches failure and returns labeled `source: 'mock'` data. Quote creation has no such fallback because a locally invented quote would look like a server calculation.

The staged project’s controller is [`WorkforceController.cs`](../src/PeblClone.Api/Controllers/WorkforceController.cs). It binds the JSON object to `HiringQuoteRequest`, calls `IHiringQuoteCalculator`, maps a failed result to HTTP 400 with ProblemDetails, and returns the DTO on success. The application boundary is [`HiringQuoteCalculator.cs`](../src/PeblClone.Application/Workforce/HiringQuoteCalculator.cs). It trims and uppercases the country and currency, checks their syntax, validates the enum and compensation, loads profiles through `IWorkforceReadModel`, checks support, computes synthetic costs, and copies required-document names into the output. The profile data comes from [`InMemoryWorkforceReadModel.cs`](../src/PeblClone.Infrastructure/Workforce/InMemoryWorkforceReadModel.cs).

For `JP` plus `Contractor`, the exact path is: the form sends the JSON; the controller delegates; the calculator finds Japan and sees `ContractorManagementAvailable == false`; it returns failure with “Contractor management is not available in Japan.”; the controller emits 400; `request` parses `detail` and throws; `QuoteBuilder` renders that message in `role="alert"`. No total is produced. A request with `DE`, EmployerOfRecord, `10000`, and `EUR` reaches arithmetic: `2100.00` employer costs plus `699` fee plus `10000` compensation equals `12799.00`, and onboarding is Germany’s lead time plus seven days.
